# 🛡️ سنگر (Sangar) — پکیج آمادگی شخصی

> یک پوشه‌ی واحد، **کاملاً آفلاین**، فقط برای خودت: درس، هوش مصنوعی، پروکسی و بکاپ —
> تا وسط فیلترینگ یا قطعی اینترنت هم «درس و زندگی» از دستت نرود.

---

## 🚀 شروع سریع (۵ دقیقه)

فایل **`پیشخوان.html`** را دابل‌کلیک کن — همه‌چیز از همان‌جا دسترسی دارد.

اولین بار (با اینترنت):
1. `ai/install/install_ai.bat` ← نصب هوش مصنوعی (فقط یک‌بار)
2. `proxy/run.bat` ← جمع‌آوری و تست کانفیگ‌های پروکسی
3. `docs/چک‌لیست-آمادگی.html` ← بقیه‌ی کارها را تیک بزن

---

│   ├── ui/                   ← رابط فارسی
│   ├── notebook/             ← جزوه‌ها و خروجی تلگرام را اینجا بریز

├── proxy/                    ← جمع‌آوری و تست کانفیگ
│   ├── sources.json          ← منابع دلخواه خودت (هر کدام خواستی اضافه کن)

│   ├── run.bat|.sh           ← اجرای collect

└── docs/                     ← راهنماها (تلگرام، چک‌لیست)

## 🤖 هوش مصنوعی — بدون API، بدون اینترنت

| قابلیت | توضیح |
|---|---|
| چت فارسی/انگلیسی | مدل `qwen3:8b` روی سیستم خودت |
| **دفترچه (NotebookLM-مانند)** | فایل‌ها را بارگذاری کن، روی‌شان سؤال بپرس |
| حالت درس | خلاصه، آزمون، فلش‌کارت، بندنویسی |
| حالت کد | نوشتن و اصلاح کد با بلاک کد فرمت‌شده |
| جستجو در تلگرام | خروجی تلگرام را در دفترچه بریز، از دل چت‌ها سؤال بپرس |

- **نصب:** `ai/install/install_ai.bat` (ویندوز) یا `install_ai.sh` (لینوکس/مک)
- **اجرا:** `ai/start_ai.bat` سپس <http://127.0.0.1:8321>
- وابستگی پایتون: **ندارد** (فقط کتابخانه استاندارد) — مدل‌ها را Ollama نگه می‌دارد.
- حریم خصوصی: سرور فقط روی `127.0.0.1` است؛ هیچ داده‌ای به جایی نمی‌رود.

## 🌐 پروکسی — تلگرام، گوگل، گیت‌هاب

1. **جمع‌آوری:** `proxy/run.bat` ← منابع را از `sources.json` می‌خواند (هر منبعی خواستی اضافه کن: `--add-source NAME URL`).
2. **تست دومرحله‌ای:** هر کانفیگ (۱) تست TCP و (۲) تست عمیق سلامت پروتکل (TLS/QUIC) را رد می‌کند؛
   با `--deep` و وجود `xray`، تست واقعیِ «باز شدن گوگل» هم انجام می‌شود.
3. **حذف خراب‌ها:** در هر اجرای جدید، کانفیگ‌های مرده خودکار از خروجی حذف می‌شوند.
4. **خروجی‌ها:**
   - `output/working.txt` ← برای import در v2rayNG / Mahsang / Npv Tunnel
   - `output/subscription.txt` ← همان‌ها به‌صورت base64
   - `output/mtproto.txt` ← پروکسی مستقیمِ خودِ تلگرام
   - `output/report.html` ← گزارش فارسی
5. **دسکتاپ:** `python proxy/start_proxy.py` ← پروکسی محلی SOCKS `10808` + HTTP `10809`
   - ویندوز برای کل سیستم: `proxy/tools/set_system_proxy.bat` (بدون ادمین، قابل خاموش‌کردن)
   - مرورگر یک‌باره: `chrome.exe --proxy-server="socks5://127.0.0.1:10808"`

## ⚠️ نکته‌های مهم

- **قطع کامل اینترنت = تلگرام زنده در دسترس نیست** (سرور ابری است). راه‌حلِ سنگر:
  پروکسی برای زمان فیلتر + بکاپ محلی برای زمان قطعی.
- هیچ‌کدام از فایل‌ها به سرور خارجی وصل نمی‌شوند؛ داده‌هات فقط روی سیستم خودت است.
- هر ۲-۳ هفته `run.bat` را بزن تا لیست پروکسی‌ها تازه بماند.
- پروژه شخصی است — از اشتراک‌گذاری لینک‌های خروجی خودداری کن.
