✈️ راهنمای قدم‌به‌قدم: بکاپ کامل تلگرام

هدف: اینکه حتی با قطع کامل اینترنت، «درس و زندگی»ات از دستت نرود — و حتی با هوش مصنوعی محلی از دلش سؤال بپرسی.

⚠️ یک واقعیت مهم: تلگرام «ابری» است؛ یعنی وقتی اینترنت کاملاً قطع باشد، هیچ نرم‌افزاری نمی‌تواند به سرور تلگرام وصل شود. تنها راه نجات داده‌ها در آن لحظه، بکاپ محلی است که الان می‌گیری. پس این راهنما را جدی بگیر.

مرحله ۱ — خروجی گرفتن (با تلگرام دسکتاپ، ۱۰ دقیقه)

  1. تلگرام دسکتاپ (ویندوز) را باز کن و وارد حسابت شو (هنوز اینترنت داری ✅).
  2. منوی ☰ سمت چپ ← Settings (تنظیمات).
  3. Advanced (پیشرفته).
  4. Export Telegram data (خروجی داده‌های تلگرام).
  5. در پنجره بازشده:
    • چت‌های موردنیاز را انتخاب کن (یا همه).
    • فرمت خروجی: JSON و هم HTML (هر دو را بزن — HTML برای خواندن، JSON برای آینده).
    • گزینه‌ی پوشه‌ی مقصد: مسیر زیر را انتخاب کن:
    ...\Aliakbar1388\sangar\ai\notebook\telegram-export
  6. اندازه‌ی فایل‌ها: اگر حجم زیاد است، اول فقط متن‌ها را بزن (مهم‌ترین بخش).
  7. Export را بزن و صبر کن تمام شود.

مرحله ۲ — ساختن «حافظه» برای هوش مصنوعی

  1. روی دستیار سنگر بزن و برو سراغ تب 📓 دفترچه.
  2. پوشه‌ی telegram-export را داخلش رها کن (یا فایل‌های html/json را انتخاب کن).
  3. منتظر بمان تا ایندکس ساخته شود.
  4. بعداً در چت، کلید 🔎 جستجو در دفترچه را روشن کن و بپرس: «از بین همه پیام‌هایم و گروه‌های درسی، فلان موضوع را پیدا کن».

مرحله ۳ — پروکسی‌های خودِ تلگرام (برای وقتی فیلتر است)

  1. فایل proxy/output/mtproto.txt را باز کن (روزی که collect زدی).
  2. در تلگرام موبایل: تنظیمات ← داده و ذخیرهسازی ← پروکسی ← افزودن پروکسی.
  3. یکی‌یکی لینک‌ها را کپی و import کن — چندتایشان را نگه دار.
  4. در تلگرام دسکتاپ هم: Settings → Advanced → Connection → Use custom proxy و اگر پروکسی سیستم (start_proxy.py) روشن است، گزینه‌ی Use system proxy را بزن.

مرحله ۴ — قوانین بکاپ‌گیری

  • 🗓 هر ماه یک‌بار خروجی تازه بگیر (وقتی اینترنت آرام است).
  • 💾 هر خروجی را روی ۲ رسانه (فلاش جدا + هارد) نگه دار.
  • 🔐 پوشه‌ی بکاپ رمزنگاری‌اش کن (با VeraCrypt یا ۷-Zip با رمز).
  • 🚫 چت‌های Secret اصلاً قابل خروجی گرفتن نیستند — اگر چیز مهمی داری، در چت معمی پین کن.
  • 📦 حجم خروجی بزرگ است؟ نسخه‌ی «متنی» برای همیشه، «مدیا» برای سال اول.
