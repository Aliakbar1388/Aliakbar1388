# تبدیل جزوهٔ NotebookLM به PDF فارسی

این پوشه یک ابزار کامل و خودکفاست که هر متنی را که از **NotebookLM** (یا هر منبع دیگری مثل Google Docs، ChatGPT، Obsidian و…) گرفته‌اید، به یک **جزوهٔ PDF فارسی و راست‌به‌چپ** با جلد، فهرست مطالب، سرصفحه، جدول و بلوک کد تبدیل می‌کند.

> بله! کافی است محتوا را برایم بفرستید (متن در چت، فایل `.md`/`.txt`/`.html` یا لینک اشتراکی)؛ من آن را با همین ابزار به PDF تبدیل می‌کنم و تحویل می‌دهم. می‌توانید خودتان هم با دستورهای پایین اجرا کنید.

## نمونهٔ خروجی

| فایل نمونه | توضیح |
| --- | --- |
| [`samples/sample-jozve.pdf`](samples/sample-jozve.pdf) | جزوهٔ ۶ صفحه‌ای «زمان‌بندی پردازنده» با جلد، فهرست، نقل‌قول، جدول و کد |
| [`samples/sample-edge-cases.pdf`](samples/sample-edge-cases.pdf) | آزمون حالت‌های خاص: لیست تودرتو، تصویر، عنوان‌های بلند، جدول چندسطری |

## قابلیت‌ها

- **راست‌به‌چپ واقعی** با شکل‌دهی درست حروف (HarfBuzz) — نه فقط چپ‌چین کردن متن.
- سرفصل‌های ۶ سطحی با فهرست مطالب **دارای شمارهٔ صفحه** و نشانک (Bookmark) در PDF.
- صفحهٔ **جلد** با عنوان، نام درس، استاد، تهیه‌کننده و **تاریخ شمسی خودکار**.
- **سرصفحه و پاصفحه**: نام فصل جاری در بالای صفحه و «صفحهٔ X از Y» در پایین.
- پاراگراف، لیست نقطه‌ای/شماره‌دار تودرتو، **جدول** با سرستون رنگی، نقل‌قول کادردار، بلوک کد با فونت مونو، تصویر و شکل‌دهی متن پررنگ/مورب.
- تبدیل خودکار **اعداد لاتین به فارسی** (قابل غیرفعال‌سازی) و پاک‌سازی نشانه‌های لاتک (`\( \)`, `\frac`, `\alpha`, `\times` …).
- ورودی از **Markdown، متن ساده یا HTML**؛ فایل‌های HTML (مثل خروجی Google Docs) خودکار به Markdown تبدیل می‌شوند.
- فونت پشتیبان برای نمادهایی که وزیرمتن ندارد (یونانی، فلش، علائم ریاضی).

## نصب

```bash
pip install fpdf2 uharfbuzz fonttools brotli pillow
# یا
pip install -r notebooklm-to-pdf/requirements.txt
```

فونت‌ها از قبل داخل `fonts/` هستند؛ برای دریافت دوباره یا به‌روزرسانی:

```bash
python3 notebooklm-to-pdf/fetch_fonts.py
```

## استفاده

```bash
# ساده‌ترین حالت: فایل مارک‌داون یا متنی
python3 notebooklm-to-pdf/md2pdf_fa.py jozve.md -o jozve.pdf

# با اطلاعات جلد
python3 notebooklm-to-pdf/md2pdf_fa.py notes.html -o jozve.pdf \
  --title "جزوهٔ درس شبکه" --course "شبکه‌های کامپیوتری" \
  --teacher "دکتر نمونه" --author "علی‌اکبر"

# بدون جلد و فهرست، با اعداد لاتین
python3 notebooklm-to-pdf/md2pdf_fa.py jozve.md -o jozve.pdf --no-cover --no-toc --latin-digits
```

### گزینه‌ها

| گزینه | توضیح |
| --- | --- |
| `input` | فایل ورودی: `.md`، `.txt` یا `.html` |
| `-o, --output` | مسیر PDF خروجی (پیش‌فرض: کنار فایل ورودی) |
| `--title / --subtitle / --course / --teacher / --author / --date` | اطلاعات روی جلد و سرصفحه |
| `--font-size` | اندازهٔ متن پایه (پیش‌فرض `11.5`) |
| `--no-cover` / `--no-toc` | حذف صفحهٔ جلد / فهرست مطالب |
| `--latin-digits` | اعداد به‌صورت لاتین بمانند |
| `--fonts-dir` | پوشهٔ فونت‌ها (پیش‌فرض: `notebooklm-to-pdf/fonts`) |

### سفارشی‌سازی جلد از داخل فایل

اگر ابتدای فایل ورودی بلوکی به شکل زیر بنویسید، همان مقادیر روی جلد می‌آیند (گزینه‌های خط فرمان اولویت دارند):

```markdown
---
title: جزوهٔ سیستمعامل — زمان‌بندی پردازنده
subtitle: بر پایهٔ یادداشت‌های NotebookLM
course: سیستمعامل
teacher: دکتر نمونه
author: علی‌اکبر
---
```

## نکته‌های عملی

- **خروجی NotebookLM**: از دکمهٔ Copy یا دانلود (Docs/Markdown) استفاده کنید و متن را در یک فایل `.md` بگذارید. اگر خروجی HTML/Docs گرفتید، همان را مستقیم به ابزار بدهید.
- متنی که از PDF یا صفحهٔ وب کپی می‌شود ممکن است «سطرهای شکسته» داشته باشد؛ پاراگراف‌ها خودکار به هم می‌چسبند و درست بازچینی می‌شوند.
- برای درج تصویر، فایل تصویر را کنار فایل متنی بگذارید و با مسیر نسبی ارجاع دهید.
- فایل‌های تولیدشده در `samples/` با همین ابزار و روی همین مخزن ساخته شده‌اند؛ برای کنترل کیفیت می‌توانید آن‌ها را ببینید.
